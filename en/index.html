DynamoDB Basic Concepts Amazon DynamoDB is a fully managed NoSQL database service that provides fast, predictable performance and seamless scalability. Basic structure DynamoDB has a few core concepts: tables, items, and attributes. A table is a collection of items, and each item is a collection of attributes. You can think of them as the equivalent of collections, documents, and fields in MongoDB.
