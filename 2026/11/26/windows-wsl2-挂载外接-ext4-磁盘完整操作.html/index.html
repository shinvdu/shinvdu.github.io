在 Windows 上通过 WSL2 直接挂载外接 ext4 磁盘，并把挂载点映射成 Windows 盘符，实现「Linux 原生读写 + Windows 资源管理器访问」。下面是完整操作流程。

准备工作（每次连接电脑后操作）

1. 查看并定位外接磁盘编号

以 管理员身份 打开 PowerShell，运行以下命令确定目标磁盘的盘号：

1

Get-CimInstance -Query "SELECT * from Win32_DiskDrive"

在返回列表中找到你的移动硬盘 Model（例如 Innostor Ext. HDD USB Device），查看对应的 DeviceID 结尾数字（例如 \\.\PHYSICALDRIVE2 即盘号为 2）。

2. 将移动硬盘在 Windows 中脱机

在 管理员 PowerShell 中运行：

1
2
3
4

diskpart
select disk 2
offline disk
exit

注：如果盘号不是 2，请将 select disk 2 中的数字替换为第 1 步查到的实际盘号。

3. 将裸盘挂载至 WSL2 内核

在 管理员 PowerShell 中运行：

1

wsl --mount \\.\PHYSICALDRIVE2 --bare

挂载文件系统与权限配置（Linux 端）

4. 查看 ext4 分区名称并挂载授权

输入 wsl 进入 Linux 界面，运行 lsblk -f 确认 TYPE 为 ext4 的分区名称（假设为 sdd3），依次执行：

1
2
3
4
5
6
7
8

# 创建挂载点目录（只需创建一次）
sudo mkdir -p /mnt/ext4_usb

# 挂载 ext4 分区
sudo mount /dev/sdd3 /mnt/ext4_usb

# 赋予 Windows 完全读写权限
sudo chmod -R 777 /mnt/ext4_usb

映射为 Windows 本地盘符

5. 映射 Z: 盘（必须使用普通用户权限）

按 Win + R 输入 powershell 回车（切勿以管理员身份运行），直接执行：

1

subst Z: \\wsl.localhost\Ubuntu\mnt\ext4_usb

完成上述步骤后，即可在「此电脑」中直接双击进入 Z: 盘进行读写。

安全移除/拔出磁盘步骤

1. 卸载盘符（普通权限终端）

1

subst Z: /D

2. 在 Linux 中卸载挂载点（在 wsl 中运行）

1

sudo umount /mnt/ext4_usb

3. 在 Windows 中卸载 WSL 磁盘绑定（管理员 PowerShell）

1

wsl --unmount \\.\PHYSICALDRIVE2

4. 恢复 Windows 识别（管理员 PowerShell）

1
2
3
4

diskpart
select disk 2
online disk
exit
